# Vouched Android Sample

This is a sample Android application demonstrating the Vouched Android SDK.

## Setup

1. Open this project in Android Studio
2. Edit `app/build.gradle.kts` and replace `YOUR_API_KEY_HERE` with your Vouched API key
3. Sync Gradle and build the project

## Requirements

- Android Studio Arctic Fox or later
- JDK 21
- Android SDK 24+ (minimum)
- Android SDK 36 (target)

## Running

Simply build and run the app on an emulator or physical device. The camera permission will be requested at runtime.
